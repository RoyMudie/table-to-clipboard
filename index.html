Table to Clipboard

This bookmarklet copies the results table on the current page to your clipboard, ready to paste into Excel. You get just the values contained in the table (including headers) with none of the page formatting.

Install

Drag this button onto your browser's bookmarks bar:

Table to Clipboard

Can't see the bookmarks bar? Press Ctrl+Shift+B (Cmd+Shift+B on Mac).

How to Use

  1. Open the webpage that shows a table.
  2. Click Table to Clipboard in your bookmarks bar.
  3. A message tells you how many records were copied.
  4. Click a cell in Excel (desktop or Excel 365 online) and press Ctrl+V. Each value lands in its own column, with no import step.

The data is copied as tab-separated text, which is what lets Excel split it into columns. Pasting into Notepad or an email gives plain text with tabs between the values.

Note: This tool will only copy the contents of the visible table on the page. If the data is split across multiple tables (e.g. a table split based on a row limit) then you can copy and paste each table views separately and merge them together in another tool like Excel.

What's copied

  • The first row has the column names, one row per member after that.
  • Text columns (e.g. ID, Name, Address, etc) are copied as shown.
  • Any images and replaced with best guess at what that image represents. E.g. Tick and cross icons become YES and NO.

Example, as it looks once pasted:

First NameLast NameAddress
JaneSmith123 Fake Street

If the page has no results table, you'll get a message saying so and nothing is copied. If it has more than one, only the first is copied.
